# 📦 仓库番 · Sokoban 推箱子

参照 1982 年经典益智游戏《仓库番》（倉庫番 / Sokoban）用纯 JavaScript 复刻的浏览器版本。
共 **12 关**，难度（最优解步数）**严格递增**，每关都内置「答案」按钮，支持**一步步点击解题**。

## 玩法

把所有 **箱子**（橙色方块）推到 **目标点**（绿色圆点）上即过关。
箱子只能推、不能拉，且推到墙角死位就再也推不动——这正是 Sokoban 的核心难点。

### 操作

| 操作 | 方式 |
|------|------|
| 移动 | 方向键 / `W A S D`，或点击屏幕方向键 |
| 撤销 | `Z` 键 或「撤销」按钮 |
| 重置 | `R` 键 或「重置」按钮 |
| 切关 | 顶部下拉框 / ◀ ▶ 按钮 |
| **答案** | 「💡 答案」按钮 → 打开解题面板，可**逐步点击**（上一步/下一步）、自动播放、调速 |

## 运行

无需任何依赖，三种方式任选其一：

```bash
# 方式一：直接双击 index.html 用浏览器打开

# 方式二：本地静态服务器（推荐，避免 file:// 限制）
cd temp/sokoban
python3 -m http.server 8765
# 然后访问 http://127.0.0.1:8765/
```

## 关卡难度

所有关卡均由求解器验证可解并回放通过，**难度大幅提升**——第 1 关就需要 **145 步**精确操作，终关需 **238 步**。
关卡使用内框型主图及其镜像/变体，避免视觉重复。

## 求解器原理

`sokoban.js` 中的求解器采用 **A\*** 搜索（求最少推动次数的最优解）：

1. **状态** = `(箱子位置集合, 玩家可达区域归一化坐标)`。
   玩家可达区域用洪水填充计算，归一化为最小坐标，消除等价状态。
2. **动作** = 每个箱子沿 4 个方向的一次推动（仅当玩家能到达推动所需的站位）。
3. **启发函数**：从每个目标点反向 BFS，预算出「每个格子把箱子推到任意目标所需的最少推动数」；
   A\* 的 h = 各箱子到最近目标的推动距离之和（admissible 下界），强力引导搜索方向。
4. **剪枝**：
   - **死格剪枝**：反向 BFS 中不可达的格子即为死格（墙角、沿无目标墙线的格子），
     箱子一旦推上去即死局，直接剪掉（与启发距离预算同一遍计算）。
   - 已访问状态按 `g(推动次数)` 去重，用最小堆按 `f = g + h` 取最优。
5. A\* 找到最少推动的最优解后，再通过「玩家最短走位路径」把每次推动
   展开成**基本移动序列**（走位 + 推动），供前端逐步回放。
