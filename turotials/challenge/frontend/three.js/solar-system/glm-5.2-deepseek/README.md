# 交互式太阳系 · Three.js

使用 [Three.js](https://threejs.org/) 实现的可交互三维太阳系页面，包含太阳以及水星、金星、地球、火星、木星，地球还带有沿其局部坐标运行的月球。

## 功能特性

- ☀️ 太阳作为中心恒星与光源，行星沿椭圆平面围绕太阳公转，并绕自身轴自转。
- 🌍 地球带有一颗月球，月球挂在地球的**局部坐标系**下运行。
- 📊 **统一数据表**配置每颗天体的相对半径、轨道半径、公转周期与自转周期（见 `src/main.js` 中的 `BODIES`）。
- 🎞️ **单一动画循环**驱动所有天体（太阳 / 行星 / 月球共用同一套更新逻辑，不为任何天体复制独立动画）。
- 🖱️ `OrbitControls` 支持左键旋转、右键平移、滚轮缩放。
- 👆 点击任意天体弹出信息面板，显示名称与物理数据。
- 📐 窗口尺寸变化时自动更新相机宽高比与渲染器尺寸。
- ✨ 星空背景 + 行星轨道线。

## 运行方式

> 需要 Node.js 16+（推荐 18+）。

```bash
# 1. 进入项目目录
cd temp

# 2. 安装依赖
npm install

# 3. 启动开发服务器（默认自动打开浏览器）
npm run dev
```

启动后访问终端提示的地址，默认为：<http://127.0.0.1:5173/>

其它命令：

```bash
npm run build     # 构建生产产物到 dist/
npm run preview   # 本地预览构建产物
```

## 数据表说明

所有天体在 `src/main.js` 顶部的 `BODIES` 数组中统一配置，字段含义：

| 字段              | 含义                                                         |
| ----------------- | ------------------------------------------------------------ |
| `key`             | 唯一标识                                                     |
| `name` / `nameEn` | 中 / 英文名称                                                |
| `radius`          | 相对地球的显示半径（场景缩放，非真实比例）                   |
| `orbitRadius`     | 距中心（太阳）的轨道半径（场景单位）；太阳为 0               |
| `period`          | 公转周期（地球年）                                           |
| `rotationPeriod`  | 自转周期（地球日；**负值表示逆向自转**，如金星）             |
| `color`           | 颜色                                                         |
| `isStar`          | 是否为恒星（自发光、作为光源）                               |
| `moons`           | 子天体数组（挂载到父天体局部坐标系，例如地球—月球）          |
| `info`            | 点击时展示的说明文字                                         |

角速度由统一公式从数据表派生，无需为每颗行星单独编写：

- 公转角速度 = `2π / (period × EARTH_ORBIT_SECONDS)`
- 自转角速度 = `2π / (rotationPeriod × EARTH_DAY_SECONDS)`

要新增一颗行星，只需在 `BODIES` 中追加一项配置对象即可，无需改动动画逻辑。

## 交互说明

- **左键拖拽**：旋转视角
- **右键拖拽**：平移
- **滚轮**：缩放
- **点击天体**：弹出名称与数据面板（右上角 × 可关闭）
