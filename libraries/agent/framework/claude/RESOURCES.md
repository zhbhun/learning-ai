# Claude Agent SDK（TypeScript）

- [@官方@Agent SDK 官方文档](https://code.claude.com/docs/en/agent-sdk/overview)
  覆盖：SDK 定位、能力地图、快速上手，以及 permissions、hooks、MCP、sessions、subagents 等全部专题页。适用于：路线设计的总依据；各课程下钻到对应专题页。
- [@官方@TypeScript SDK 参考](https://code.claude.com/docs/en/agent-sdk/typescript)
  覆盖：`query()`、Options、Query 方法、SDKMessage 类型、hook 与权限类型的完整 API 手册。适用于：所有课程写代码与回查 API 细节的权威入口。
- [@官方@Agent SDK 官方示例集](https://code.claude.com/docs/en/agent-sdk/examples)
  覆盖：官方按场景整理的可运行示例（子代理、hooks、MCP、权限等）。适用于：课程范例设计与对照官方写法。
- [@官方@claude-agent-sdk-typescript 仓库](https://github.com/anthropics/claude-agent-sdk-typescript)
  覆盖：SDK 源码与类型定义、CHANGELOG 版本记录、examples/ 目录与 issues。适用于：核对类型定义、跟踪版本变化、查已知问题。
- [@官方@MCP TypeScript SDK 仓库](https://github.com/modelcontextprotocol/typescript-sdk)
  覆盖：官方 MCP server/client TypeScript SDK，stdio 与 Streamable HTTP transport。适用于："自建 MCP server"课程与 MCP 扩展开发。
- [@官方@MCP 官方文档](https://modelcontextprotocol.io)
  覆盖：MCP 协议概念、server 开发与调试指南。适用于：MCP 相关课程的协议背景与规范查询。
