### README.mdx 结构（按 CHEATSHEET-FORMAT.md）

`# {短标题}` → 无标题导读（本课是什么、能解决什么、对象如何配合）→ 可选 Mermaid 开场图 / 开场参考表（默认值回查）→ 主题小节（`##` 主体，`###` 成员；每节按「这是什么 → 最小代码 → 可观察证据 → 必要边界」展开）→ 按需 `## 最佳实践` / `## 常见问题` → `## 总结回顾`（固定三槽位：摘要 / 一句话 / 知识要点）→ `## 参考资料`。

- H1 短标题不加序号，不写「详解 / 速查表 / 正文」类形态词
- MDX 正文避免裸 `{` 和未成对 `<`（放入代码块或改写句子）
- Mermaid 用 ```` ```mermaid ```` 围栏
- 语言：标题、正文、注释全中文；API 名、包名、命令、代码标识符保留英文
- 不写「下一课 / 下一步」；课程间跳转链接用 `?path=/docs/<对方slug>--docs`

### 内嵌实例（推荐默认）

Mastra 真实代码以**正文代码块 + Show code 源码**呈现；Canvas 实例一律**离线示意**（Canvas 2D 画流程、层级、时间轴、对比读数），不调用真实 LLM / 网络 / 数据库。

带实例课程建 3 类文件（均在课程目录内）：

1. `<示例核心文件>.ts` —— 示意实现本体，开头写短注释（演示内容 / 输入 / 操作 / 预期结果 / 阅读主线），Show code 只绑定这个文件
2. `<slug>.stories.ts` —— 模式照抄 sample-course：

```ts
import type { Meta, StoryObj } from '@storybook/html-vite';
import { canvasStory } from '../../assets/story-canvas.js';
import { storySource } from '../../assets/story-source.js';
import exampleSource from './<示例核心文件>.ts?raw';

interface <Course>Args { /* 1~3 个读者可调输入 */ }

const render = canvasStory({
  create: <createFn>,              // (canvas, emit) => Instance
  apply(instance, args) { instance.update(args); },
  readout(snapshot) { return [['读数名', snapshot.x]]; },
});

const meta = {
  id: '<slug>',                    // 全局唯一，等于课程目录名
  title: '<中文层级>',
  tags: ['!dev'],
  args: { /* 初始输入 */ },
  argTypes: { /* 中文标签 + control 类型 */ },
  render,
  parameters: storySource(exampleSource),
} satisfies Meta<<Course>Args>;

type Story = StoryObj<typeof meta>;
export const Interactive: Story = {};   // 可按机制拆多个具名 story
```

3. README.mdx 头部绑定：

```mdx
import { Canvas, Controls, Meta } from '@storybook/addon-docs/blocks';
import * as Stories from './<slug>.stories';

<Meta of={Stories} name="Docs" />
```

实例位置：`<Canvas of={Stories.Interactive} />` 放在对应主题小节；正文要求读者调输入时紧跟 `<Controls of={Stories.Interactive} />`。Storybook 永久链接为 `?path=/docs/<slug>--docs`。

**Storybook 10 控件坑**：`radio` / `select` 的可选项 `options` 必须写在 argType **顶层**（与 `control` 平级），写进 `control.options` 会渲染为 "-"；中文显示用 argType 顶层的 `options` + `control.labels`。

**工程纪律**：不运行 tsc / storybook build / 浏览器验证（课程阶段按技能边界不做工程验收），不执行 npm 安装；靠严格对齐上述模式保证正确性；工具调用总数控制在 25 次以内，高效直给。

### canvasStory / 运行时契约（assets 由模板提供，不得修改）

- `canvasStory({ create, apply, readout?, captions? })` 返回 `(args) => HTMLDivElement`：
  - `create: (canvas: HTMLCanvasElement, emit: (snapshot) => void) => Instance` —— 创建实例，返回 `{ update?, dispose? }`
  - `apply: (instance, args) => void` —— args 每次变化时调用（首次也会调用）
  - `readout: (snapshot) => Array<[string, unknown]>` —— 左下角读数行
  - `captions?: string[]` —— 舞台角标（第 1 个居左、第 2 个居右）
- 尺寸与生命周期用 `../../assets/canvas-runtime.js` 的 `readCanvasSize(canvas)`、`createResizeObserver(canvas, draw)`；动画循环用 `createRenderLoop(element, frame)`（自动离屏暂停）；在 `dispose()` 中释放
- 静态绘制课在 `create` 中画一次即可，不必用动画
