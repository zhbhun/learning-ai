# REA

- [@官方@REA 官方站点](https://rea.tools/)
  覆盖：入门指南、分平台安装、JavaScript/Electron 与原生、浏览器三条主分析线的指南、FAQ。适用于：入门阶段全部课程，以及各阶段课程的一手依据。
- [@开源@morluto/rea 仓库](https://github.com/morluto/rea)
  覆盖：源码、`docs/` 完整文档（cli.md、mcp-contracts.md、mcp-prompts.md 与各目标类型指南）、架构图、迁移指南、版本记录。适用于：所有课程的一手来源，课程内容以这里为准。
- [@官方@rea-agents npm 包](https://www.npmjs.com/package/rea-agents)
  覆盖：发布版本历史、安装方式与包元信息。适用于：安装、更新与版本相关课程。

## 缺口
