# Glossary

The ubiquitous language for this repo. Use these terms exactly as defined.

| Term | Meaning |
|------|---------|
| artifact | The `app.tgz` tarball built from `src/` |
| promote | Copy the artifact to a target and make that target serve it |
| target | A place the app is served from: `staging` or `prod` |
| live | The version users get right now |
