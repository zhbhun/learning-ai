# Triage labels

Five canonical roles. Each label string equals its role name:

- `needs-triage` — new issue, not yet assessed
- `needs-info` — blocked on missing information
- `ready-for-agent` — ready for an agent to implement
- `ready-for-human` — ready for a human to implement
- `wontfix` — decided not to do

In local-markdown trackers, the label is recorded as a `Status:` line near the top of each issue file.
