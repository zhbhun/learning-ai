# teach

> 在当前工作区里系统地教会用户一项新技能或新概念（仅手动）

## 场景

用户想学会用 git rebase 整理 PR 里的凌乱提交，在空目录里首次运行 /teach——技能的第一次运行要建出整套教学工作区（使命、资源库、组件库）并产出第一课。技能要求 mission 不明时先反问用户，这次子代理判断请求里动机已足够具体，没有反问、直接开工。

## 对话

- /teach 我想学会用 git rebase 整理 PR 里的凌乱提交（squash、改 message、调整顺序），让提给团队的 PR 历史干净可读。教学工作区就建在当前目录。

  ```md
  教学工作区已建好，第一课已发布并在浏览器中打开。

  ## 工作区（报告同级的 sandbox/）
  - **MISSION.md** — 使命：提给团队的 PR 历史干净可读；明确划出本阶段不学 `rebase main`/冲突
  - **RESOURCES.md** — 全部实测 200：Pro Git《重写历史》中英文、Julia Evans《git rebase: what can go wrong?》（jvns.ca 2023 正确 URL，实测找到）、git-rebase 官方手册、Oh Shit Git 中文版、learngitbranching.js.org 等社区

  - **assets/** — `course.css`（共享样式：终端窗口、提交图示、步骤条、测验、模拟器，浅/深主题自适应+打印样式）、`quiz.js`（即时反馈测验组件）、`sandbox.js`（浏览器内 rebase 模拟器，支持拖拽排序、squash/fixup/reword/drop 与规则校验）

  - **setup-sandbox.sh** + **practice-repo/** — 8 个提交的练习仓库（模拟“调研报告”场景：2 个正经提交 + 4 个 wip/fix 碎提交 + 2 个 aha），幂等可重建

  下一步：你练完第一课后回来说一声，我会写学习记录并按最近发展区排第二课（rebase main、冲突处理、黄金法则）。有不懂的随时问。
  ```

## 总结

直接问 AI「git rebase 怎么用」，得到的是一段解释，看完就忘；这个技能把「学东西」变成一个跨会话的教学工作区：agent 先把你的学习动机写成 MISSION.md（做什么、学到什么算成、明确不学什么），自己去找高可信资料并逐条验证链接可用，然后产出能在浏览器里打开的交互式课程——讲解、真实仓库练习、网页版模拟器、凭记忆的测验各占一环，再配上可打印的速查表和一个自带凌乱提交的练习仓库。学过的东西记进学习记录，下次运行时它据此判断你现在的水平，接着排下一课而不是从头再来。

实测最突出的两点：一是资源不靠模型记忆瞎编——每个链接都实测返回 200，Julia Evans 那篇文章的 URL 还是搜索后确认的正确版本；二是课程交付前自己先验过货，在练习仓库副本上按课程的步骤真跑了一遍 rebase，确认照做就能得到课程承诺的结果。局限：首次运行就是「建工作区 + 授课」一条龙，耗时约 36 分钟，急用的人会嫌慢；课程在浏览器打开需要联网加载外链资源时才完整（资源验证环节需要网络）。
