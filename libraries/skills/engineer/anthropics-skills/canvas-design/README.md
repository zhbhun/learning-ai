# canvas-design

> 用设计哲学创作精美的视觉艺术，输出 .png 与 .pdf 文档；用户要做海报、艺术作品、设计稿或其他静态作品时使用

## 场景

一家新开的社区咖啡馆要一张开业海报，子代理按技能流程先写设计哲学、再画海报，两份产物落在 sandbox/ 下，已核对与日志一致。

## 对话

- /canvas-design 为一家新开业的社区咖啡馆做一张开业海报，把产出文件放到 libraries/skills/engineer/anthropics-skills/canvas-design/sandbox 目录下

  ```md
  完成。已按 canvas-design 技能的两步流程（设计哲学 → 画布表达）产出，文件均在 `sandbox/` 下：

  1. **design-philosophy.md** — 设计哲学「晨光定量 · Measured Dawn」：晨间光线可测量的定量美学。暖色四阶温标（奶油纸底、浓缩咖啡深褐、烘焙赭石、日出金）、七分呼吸三分实体的负空间原则、系统观测的图形语言（刻度、同心弧、点阵）、文字作为标本标签、反复强调大师级工艺。

  2. **poster.pdf** — 单页海报（540×760pt 竖版）。画面即一份“晨间观测手册”：
     - 唯一的超大字宣言「晨光定量」（Songti Black，系统字体）+ 金色等宽副标
     - 左侧竖直刻度轴：06:30–10:00 六个时刻的光线累积点阵，由金渐入墨
     - 右侧主视觉：俯视咖啡杯的观测刻度盘（72 格刻度 + 同心圆环），烘焙弧线即金色油脂环，缺口朝向光源，一枚孤点标记“第一缕晨光落入杯中”
     - 嵌入式内行彩蛋：SCA 金杯萃取参数（92°C、1:2、25–30s）作为仪器读数标签——懂咖啡的人会心一笑，旁人只觉是图版注记
     - 底部信息带：11月21日 周六 晨 07:00 开业（2026年11月的周六）· “社区的第三个空间”

  经过三轮渲染迭代：修正了首版读数区与点阵轴重叠的硬伤，第二版将参数改为表盘下方的三格仪表行，第三版对齐标题基线、收窄油脂环并在弧口加入晨光孤点。最终版无任何元素重叠或出界，色彩严格限定在四阶暖色内。技术栈：reportlab 绘制 + GeistMono 技能字体 + Songti 中文字体，pdftoppm 栅格化预览校验。
  ```

## 总结

canvas-design 是把一句模糊的设计需求变成一张正式海报（PDF/PNG）的技能。它分两步干活：先写一篇「设计哲学」，给这次创作立一套完整的美学运动——起个名字、定下色板、留白原则和图形语言；再照着这套哲学用代码把画面一寸寸画出来。试用下来最明显的价值是成品的「整体感」：海报有统一的美学语言（本例是「晨间观测手册」式的定量美学），而不是各元素拼凑的通用 AI 风；中英文混排的字体问题也靠自带的字体库解决了。技能里「不允许重叠、不允许出界、必须再打磨一轮」的硬约束是真实起作用的——子代理首版就出现了读数区与点阵轴重叠，随后自己迭代三轮才收尾。局限：一次调用不便宜（本例约二十分钟），且依赖本地有 Python 绘图环境；产出是 PDF/PNG 文件，效果要自己打开确认。
