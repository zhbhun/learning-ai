## 总结

这个技能把「用代码画一幅生成艺术」拆成两步：先让 Claude 为作品写一篇艺术运动宣言（算法哲学 .md），再照着宣言实现一个 p5.js 网页作品（自包含 HTML，浏览器直接打开就能玩）。页面骨架来自模板——侧边栏、种子导航、参数滑杆、下载按钮全是固定件，Claude 只负责替换算法和参数，所以每次产出都是「同一个展柜、不同的作品」。

试用里它以「深海生物发光」为题写出《深渊辉光》宣言，把主题翻成可执行的规则：黑暗是底色、光是扰动事件、蓝绿光谱占九成、隐形的鮟鱇猎手只露诱饵——最终算法逐条照做：2600 个浮游体平时近暗、相遇才闪光，猎手永不上画，换一个种子就是一片没人见过的海域。全程没有向用户提问的环节，运动命名、参数取舍都由 Claude 自行决定，一次派发直接拿到成品。

最明显的局限是外观：页面被模板钉死在 Anthropic 品牌风格上（浅色、固定侧边栏），想要别的页面观感只能改模板；作品本身倒是每次都不同。
