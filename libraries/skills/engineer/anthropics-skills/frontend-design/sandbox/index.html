这间店

拾遗书局开在老城中山路的骑楼下，二〇〇九年到现在。我们收旧书、卖旧书，也修旧书——书脊散了、书页黄了的书，在这里补好，等下一位读者。

店里没有"新书区"。每一本都带着上一位主人的痕迹：扉页的题字、页边的批注、夹了三十年的一张车票。买书的人常常买走的不是一本书，是这些痕迹的延续。

书怎么来

街坊搬家清出的、老人子女送来的、旧书摊上淘的。上门收书不嫌少：一捆也好，一书柜也好。价钱按品相和稀罕程度当面谈，不压价。

来路

开店的人原先在造纸厂做装订，厂子关了，就用手艺换了营生。店名取自"拾遗补阙"——旧书散了容易，收拢难，我们就做收拢的事。

  1. 二〇〇九中山路骑楼下开了这间店，第一批书来自街坊搬迁。
  2. 二〇一四添了修书的台子，开始接装订和补页的活。
  3. 二〇一九办了第一次"批注展"，把书里别人写的字展出来。
  4. 二〇二三开始每月一次的旧书交换会，带一本书来，换一本走。

架上

书按来路和内容分四架，每架隔一阵就换一批——旧书只有一本，见过就未必再有。

文史

地方志、老照片集、口述史。老城这一带的研究者常来翻。

现存六十一册，近收《县志》民国铅印本一套
文学

小说、诗、散文，以八九十年代版本为多，品相整体最好。

现存一百四十余册，近收《围城》一九八〇年一版一印
旧课本

五六十年代到九十年代的语文、算术、自然课本。批注最多的一架。
