# brand-guidelines

> 把 Anthropic 官方品牌色与字体规范套用到任意能受益于该视觉风格的产物上；凡涉及品牌色、样式规范、视觉排版或公司设计标准时使用。

## 场景

用户要一份 3 页的「Sprint 42 复盘」PPTX，按 Anthropic 品牌风格排版。沙箱是主会话预建的空目录；该技能纯知识型（一页色板加字体表，无脚本无模板），生成代码全由子代理现场编写。技能没有「问用户」环节，子代理把「sandbox 目录」默认落在了仓库根的 sandbox/，验收时由主会话把产物与生成脚本归位到本报告的 sandbox/ 并清理残留。

## 对话

- /brand-guidelines 请帮我做一份 3 页的 PPTX 演示文稿，主题是「Sprint 42 复盘」，按 Anthropic 品牌风格排版，文件保存到 sandbox 目录下

  ```md
  已完成。3 页 PPTX 已按 Anthropic 品牌风格生成并验证通过。

  **文件位置**：`sandbox/Sprint-42-复盘.pptx`（33KB，3 页 16:9）

  **品牌应用**（依据 brand-guidelines skill）：
  - 配色：暗色 `#141413`、浅色 `#faf9f5`、中灰 `#b0aea5`、浅灰 `#e8e6dc`；强调色橙 `#d97757` / 蓝 `#6a9bcc` / 绿 `#788c5d`
  - 字体：标题 Poppins（Arial 回退）、正文 Lora（Georgia 回退），中文 run 额外钉定 PingFang SC 作为东亚字体保证渲染一致

  **页面内容**（复盘数据为示例占位，可直接改）：
  1. **封面**（暗底）— Sprint 42 复盘，迭代周期 2026.10.26–11.06，三色 accent 装饰
  2. **本周期回顾** — 4 个指标卡（完成任务 34、完成率 92%、速率 38pts、缺陷 2）+「做得好 / 待改进」双栏卡片
  3. **行动项与下一步** — 3 条行动项（负责人 + 截止时间）+ 底部暗色横幅标注 Sprint 43 目标

  生成脚本在 `sandbox/make_pptx.py`，如需调整文案或数据可直接改脚本重新生成。
  ```

## 总结

这个技能本质上是一页「品牌速查卡」：四种主色、三种强调色、两套字体（标题 Poppins、正文 Lora）加各自的用途说明，别无他物。装了它，Claude 做任何视觉产物——幻灯片、海报、网页——都有一套现成的官方色板可依；没装的话，Claude 只能凭训练记忆里的模糊印象拼颜色（示意）。试用里子代理读完这一页，自己用 python-pptx 从零写出全部生成代码，产出的 PPTX 经解包核验，七种色值与规范逐字吻合，中文文字还额外钉定 PingFang SC 保证渲染一致。

局限也来自这种「只给规范、不给工具」的极简：环境里得有对应产物手段（本例是 python-pptx），本机没装 Poppins/Lora 时只能落到 Arial/Georgia 回退，观感会打折；技能不规定版式，每页布局全由 Claude 即兴发挥，两次使用的版面可能差别不小。
